# План: вкладка «Термин» (SPEC §2 п.2)

Статус: **план, кода нет** — ждёт «да». Главный документ — `translators/SPEC-translators.md`.

## Что увижу на экране

**Вкладка «Термин»** (вторая, после «Сюжета»):

1. **Строка поиска** — английское слово или сочетание («Ursus», «Rhodes Island»). Ищется по ВСЕМ текстам игры,
   по целым словам, без учёта регистра (переключатель «с учётом регистра» — для имён).
2. **Сводка:** «Ursus — 1 873 строки: сюжет 1 381 · интерфейс 402 · имена 12 · плагин 78» и рядом — запись глоссария
   («Ursus → Урсин», если есть).
3. **Фильтр по категориям** — нажимаемые плашки (`FilterChip` проекта) с числом: Сюжет · Интерфейс · Имена ·
   Игровые данные (операторы, предметы, враги, этапы — где удалось определить) · Плагин.
4. **Группы по вариантам перевода** с учётом падежей (ё=е), самая большая сверху:
   «Урсус (урсуса, урсусе…) — 1 338 строк» · «Урсин — 5 строк» · «без перевода слова — 12». Каждая группа
   сворачивается (`Collapsible`). Форма глоссария помечена ✓.
5. **Строки внутри группы** — плотная таблица как в «Сюжете»: флажок | источник понятным языком | English (найденное
   слово подсвечено) | Русский (вариант подсвечен). Источник: «Сюжет › Пролог › 0-1 Свернуть › строка 2» (ссылка на
   строку), «Интерфейс › 11_ui», «Имена › 13_names», «Оператор › Амия › Навык 2 › описание» (если строка совпала с
   полем gamedata), «Плагин › роль skill». Длинные группы — по 50 строк с «Показать ещё».
6. **«Переименовать…»** (кнопка над группами, для выбранных флажками строк; «выбрать всю группу» — одним
   флажком у группы): окно «Старая форма → новая» (старая — выбор из вариантов, новая — поле), **предпросмотр**
   каждой строки «было → станет» с заменой окончаний по падежам (Урсуса → Урсина, Урсусе → Урсине), у каждой
   строки можно поправить текст руками или снять галочку; внизу — «Создать предложения (N)». Создаются обычные
   предложения (как «Предложить»), их потом утверждает ведущий; строки, которые встречаются в нескольких местах,
   — с тем же предупреждением, что и в «Сюжете».
7. **«Найти везде»** — в любой строке (Сюжет, Глоссарий › Показать строки, Мои правки) выделяю английское слово →
   рядом с выделением появляется маленькая кнопка «Найти везде» → открывается «Термин» с этим словом. Плюс
   «Найти везде» у каждого термина во вкладке «Глоссарий».

## Из каких частей проекта

Кнопки, поле поиска (`SearchField`), плашки фильтра (`FilterChip`), сворачиваемые группы (`Collapsible`), таблица
(`Table`), окно переименования (`Dialog`), флажки (`Checkbox`), поле правки (`Textarea` / наша плашка ника),
`Badge`. Ничего своего.

## Как устроено (коротко)

- **Один общий список всех текстов** (таблица `translators.texts`, пересобирает импорт): строки сюжета (уже есть),
  все записи словарей 11_ui / 12_story / 13_names (≈ 522 тыс.), каталог плагина RichTextFix по ролям. У каждой
  строки — категория и источник. Для «Игровых данных» импорт сверяет английский текст с полями gamedata
  (имена и описания операторов, навыков, талантов, предметов, врагов, этапов) — совпало → понятный источник,
  не совпало → «Интерфейс › прочее». (Полная разметка интерфейса по разделам игры — это уже вкладка «Категории».)
- **Быстрый поиск по словам** — индекс Postgres (`pg_trgm`, расширение уже стоит) + точная проверка границ слова.
- **Варианты перевода** — тот же расчёт, что колонка «Как в игре» в глоссарии (основы слов, склейка сочетаний),
  только для найденных строк; строку относим к варианту, который в ней есть.
- **Замена с падежами** — меняется основа слова, окончание остаётся (Урсус|а → Урсин|а); в предпросмотре видно
  каждое изменение, сомнительные (основа не нашлась) — без автозамены, только руками.
- **Предложения для строк не из сюжета** (интерфейс, имена): сейчас предложение привязано к месту в сюжете. Добавлю
  «место» = запись словаря / каталога (ключ уже английский текст — выгрузка не меняется). Строки плагина — как
  сейчас: в plugin.csv.

## Что не делаем в этой вкладке

Разметку интерфейса по разделам игры и карточки объектов (это «Категории»), переименование в самом глоссарии
(«в глоссарий» — в «Категориях»), правку в Google Таблице.
