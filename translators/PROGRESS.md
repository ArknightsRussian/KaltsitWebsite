## Решил сам
- Изменённая строка: часть до разделителя `=` остаётся байт в байт как в файле пака, кодируется только значение
  (§3.2); если строка после замены читается не так (проверка декодером §3.1) — не меняется. Комментарий после
  значения (`… // хвост`) при замене пропадает (значение пишется целиком заново).
- Записи, которых нет ни в одном из 11_ui / 12_story / 13_names (реплика без перевода в игре), дописываются в конец
  копии 12_story.txt — в её же переводах строк; в отчёте «новая запись».
- story_lines.tsv: «файл сюжета» — путь сценария из библиотеки (`obt/main/level_main_00-01_end`); «строка» — номер
  строки в EN-сценарии сайта (первая строка склеенной логической строки); у выбора игрока — `строка.вариант`
  (`57.2`). Правка записи (для всех мест) даёт строку на каждое её место в сюжете; правка «только для этого места»
  заменяет её на своём месте.
- plugin_strings.tsv: роль — `story` (другие роли каталога разбор не трогает: «формат не изучать»).
- «Короткая реплика» (без «только для этого места»): меньше 20 видимых знаков или меньше 3 слов.
- Архив: свой маленький ZIP на flate2 (без новой зависимости); имя `translators_<дата>.zip` / `translators_REVIEW_<дата>.zip`.
- В архив не кладётся пустой TSV; изменённых словарей нет — только report.txt (+ TSV).
- 00_translators.txt остался вторым форматом в том же окне, с шапкой «ДЛЯ ПРОВЕРКИ У СЕБЯ» и Alt+R.

- Архив упаковывается в фоне после «Подготовить» и скачивается по номеру (30 мин, ≤ 4 в памяти): прямая сборка ~18 с, а сервер сайта рвёт молчащий запрос через ~10 с.
