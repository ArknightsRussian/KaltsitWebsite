## 3. Работа с вариантами строки ✅
- Ключ правки — английский текст записи словаря; одно решение действует во всех местах.
- Статусы: не проверено / есть предложения / утверждено (в т.ч. «как в игре — проверено») / устарело.
- Действия: «✎ Предложить» (наведение на русский текст или двойной щелчок), «Предложить этот» у варианта Совы/ИИ, «Замечание», «Заметка».
- N > 1 мест: окно «это предложение, в игру — после утверждения»; «для всех N мест» (список мест с соседними репликами + галочка «Я понимаю…»). ✅ «Только для этого места» — **только для строк сюжета и не коротких реплик** (≥ 20 видимых знаков и ≥ 3 слов; Kolooo пакует сюжет в бандлы игры по репликам); такая правка не идёт в словари, а идёт в story_lines.tsv. В интерфейсе и у коротких реплик выбора нет (у элементов нет своего id, одинаковый английский = один перевод везде) — вместо него подсказка «Этот текст встречается в N местах — перевод изменится везде»; API такое предложение отклоняет. Строки из одних знаков — правку не давать. Многострочная реплика — правится целиком.
- `{@nickname}` — неделимая плашка с ником пользователя.
- Комментарии: «Замечание» (можно «решено») и «Заметка переводчика» (постоянная, можно к варианту); цитата выделенного фрагмента; ничего не удаляется при утверждении/устаревании.
- Отметки у каждого варианта (только ошибки): глоссарий, теги, подстановки, переносы, длина (+15 % и > 15 знаков; ✅ приведено к SPEC 09.11, было 30 %), ты/вы.
- «Рекомендуем» — правило Б: звёздочка только если у текста игры есть отметка (правило А выключено в коде). ❓ решение команды по Сове.
- «Согласен» (палец, счётчик, кто), «Сцену прочитал(а)».
- Ведущий: «Утвердить» / «Снять утверждение», пачкой «утвердить рекомендованное, кроме отмеченных» и «вся сцена — как в игре, проверено»; фильтр.

## 4. Выгрузка ✅ (по ответам Kolooo и Romanov, 10.11; проверка в игре — 09.11)
- Режимы: «утверждённое — для игры» (ведущий и сборщик пака) и «все предложения — на проверку» (REVIEW в именах файлов, все участники). Без изменений.
- ✅ **Главная выгрузка — один архив .zip** («Мои правки» → «Выгрузить…» → «Скачать архив»):
  - **исправленные копии** `11_ui.txt` / `12_story.txt` / `13_names.txt` — только изменённые; в изменённой строке меняется только значение (кодирование §3.2), часть до `=` — как в файле пака; остальные строки, их порядок, комментарии, кодировка, BOM и переводы строк (CRLF/LF) — байт в байт (без правок — файл, равный оригиналу по sha256). Записи, которых нет ни в одном файле, — в конец копии 12_story.txt;
  - `plugin_strings.tsv` (если есть правки) — строки, вшитые в плагин RichTextFix: английский | было | стало | роль (из каталога, сейчас `story`); в словари такие строки не идут;
  - `story_lines.tsv` (если есть правки сюжета) — для бандлов: все утверждённые правки сюжета, каждая со своим местом: файл сюжета | строка | английский | было | стало. Файл — путь сценария (`obt/main/level_main_00-01_end`), строка — номер строки EN-сценария, у выбора игрока `строка.вариант` (`57.2`). Правка «для всех мест» — строка на каждое место; «только для этого места» — на своём месте;
  - `report.txt` — каждая изменённая строка: файл, номер строки, было → стало, кто утвердил; счётчики TSV; что не записано.
- ✅ Второй формат — `00_translators.txt` «для проверки у себя» (шапка + подсказка Alt+R; в отчёте — какие файлы его перекрывают по §3.3). Применение: файл в BepInEx\Translation\ru\Text → в игре Alt+R (или перезапуск).
- **TSV:** UTF-8 без BOM, переводы строк LF, первая строка — заголовки, разделитель — таб. В ячейке экранируется: `\` → `\\`, таб → `\t`, перевод строки → `\n`, CR → `\r` (других замен нет).
- Кодирование словарей — как в ките (§3.2), тест «туда-обратно» (§3.1); тесты побайтности копий (CRLF, LF, BOM).
- ✅ «Вышло в паке <версия>» (сборщик пака): отмечаются все утверждённые записи, ещё не выходившие с тем же текстом; у утверждённого варианта — «вышло в паке N».
- Формат каталога плагина и его DLL не разбираем.

## 6. Путь замечания от игры (согласовано с Kolooo) 📋
1. Тестер: F9 → обвести → тип, исправление/комментарий → «Собрать отчёт» → zip.
2. Загрузка zip на вкладке «Отчёты тестеров» (без дублей).
3. Ошибки текста → к строке: предложение (source = kit), замечание, скриншоты.
4. «Вылезает за края» → к строке (сократить) или «это техническое» → Kolooo; память «вылезало при длине N».
5. Картинки → «Текстуры»; другое/системное → «Технические задачи» (открыто → в работе → исправлено в паке N).
6. Утверждение (Romanov) → выгрузка (Kolooo) → пак → «в игре» → прогресс; тестер очищает принятые правки в своём 00_review.
